60 seconds of Aura

fn square(x: i64) -> i64 { x * x }

fn main() -> i64 {
    let scores = vec_new()
    vec_push(scores, square(7))
    while scores.len < 5 {
        vec_push(scores, vec_get(scores, scores.len - 1) + 1)
    }
    match read_file("data.txt") {
        Ok(t)  => println(t),
        Err(e) => eprintln("nope: " + e),
    }
    return 0
}

No semicolons. `if` and `match` are expressions. `Result` + `?` for errors. Full tour →

Compiled & interpreted

aura run interprets for iteration speed; aura build emits a native .exe through Cranelift + LLD. Same observable behavior — proven by a 50-scenario differential suite.

Batteries included

Strings, growable vectors, files, stdin, process args, environment variables, subprocess spawn — in the prelude, no imports needed. std reference →

Self-contained

The installer ships the linker and runtime. No Rust, no Visual Studio, no admin rights. One aura.exe is the whole toolchain.

Honest errors

Every diagnostic carries a stable code — aura doc E2101 explains it offline, and the error index lists all of them.
