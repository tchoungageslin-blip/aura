Recommended: the installer

AuraSetup-0.1.0-alpha.exe

A setup wizard: chooses an install directory (default %LOCALAPPDATA%\Programs\Aura), adds aura to your PATH, optionally associates .aura files, and can install the VS Code extension. No administrator rights needed.

Portable ZIP

aura-0.1.0-alpha-windows-x86_64.zip

Unzip anywhere, add the folder to PATH. Contains aura.exe, the runtime, the bundled linker, the VS Code extension (.vsix), examples and the documentation.

Verify your download

Each release publishes SHA256SUMS.txt. On Windows:

certutil -hashfile AuraSetup-0.1.0-alpha.exe SHA256

Compare the hash with the matching line in SHA256SUMS.txt.

First run

aura --version
aura new hello
cd hello
aura run

Windows SmartScreen may warn on first launch (unsigned alpha binary): More info → Run anyway.

VS Code extension

In VS Code: Ctrl+Shift+P → Extensions: Install from VSIX… and pick editors/vscode/aura-lang-0.1.0.vsix from the package — or let the installer do it. The extension gives you diagnostics, hover, go-to-definition, document outline and formatting, powered by aura lsp.
