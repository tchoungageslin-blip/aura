VS Code extensionExtension VS Code

In VS Code: Ctrl+Shift+P → Extensions: Install from VSIX… and pick editors/vscode/aura-lang-0.1.0.vsix from the package — or let the installer do it. The extension gives you diagnostics, hover, go-to-definition, document outline and formatting, powered by aura lsp.Dans VS Code : Ctrl+Shift+P → Extensions: Install from VSIX… et choisis editors/vscode/aura-lang-0.1.0.vsix dans le package — ou laisse l'installeur le faire.
